I spend too much time in fast-moving online debates. The useful evidence is usually somewhere in my camera roll, bookmarks, or cloud drive - but "somewhere" is not good enough when the conversation moves in seconds.

**SNRBoost** is a hobby project for increasing the signal-to-noise ratio of those conversations. The idea is simple: turn a disorderly archive of screenshots, charts, and saved posts into a collection that can be searched by meaning.

## The retrieval pipeline

{{< mermaid >}}
flowchart LR
  A[Images and saved posts] --> B[OCR and metadata]
  B --> C[Multimodal embeddings]
  C --> D[(Vector index)]
  Q[Natural-language query] --> D
  D --> R[Ranked evidence cards]
  R --> E[Browser and mobile clients]
{{< /mermaid >}}

The first version does not need an autonomous agent. It needs a dependable ingestion and retrieval loop:

1. Import an archive from Google Photos, Drive, or a local folder.
2. Extract visible text with OCR and retain source metadata.
3. Produce embeddings for the text and the image context.
4. Index each item for semantic retrieval.
5. Return a small, ranked set of evidence cards for a natural-language query.

A search for `historical employment data`, for example, should surface the relevant charts even when that exact phrase never appears in their captions.

## Where multimodal models help

OCR is necessary but incomplete. A chart's meaning lives in its axes, visual encodings, source, and time range - not only in the words printed on it. A vision-language model can add structured context:

```json
{
  "chart_type": "line",
  "subject": "employment rate",
  "geography": "United States",
  "period": "2000-2024",
  "source": "BLS"
}
```

That description becomes searchable context, but it should never replace the original artifact or its source. Retrieval needs provenance as much as relevance.

## The product surface

The natural desktop interface is a browser extension: enter a phrase, inspect the top matches, then copy the image and its citation. A mobile share extension can provide the same loop without forcing a context switch.

The difficult part is not generating descriptions. It is building trust: deduplicating near-identical images, preserving sources, exposing uncertainty, and keeping the result fast enough to use in the moment.
